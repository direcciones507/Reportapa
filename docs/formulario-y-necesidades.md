# Requisitos del formulario ciudadano

## Daños y ubicación
- Provincia, distrito, corregimiento, comunidad.
- Nombre y teléfono de contacto (privados).
- Enlace compartido de Google Maps (privado; no exigir coordenadas).
- Tipo de daño, descripción y hasta tres fotografías.

## ¿Qué ayuda necesita su familia?
Campo opcional de selección múltiple:
- Agua potable
- Alimentos
- Pañales para bebés
- Pañales para adultos
- Medicamentos
- Ropa y cobijas
- Colchones o lugar para dormir
- Materiales para reparar la vivienda
- Artículos de higiene
- Otra necesidad

Campo de texto libre opcional: "Explique qué necesita" (por ejemplo, cantidades o tallas). No solicitar diagnósticos ni datos médicos sensibles.

## Administración
- Ver necesidades por caso y filtrar por provincia, distrito, corregimiento y tipo de necesidad.
- Estados del reporte: pendiente, contactado, visitado.
- Datos personales y ubicación exacta solo en panel autenticado.
- Exportación CSV para Excel con controles de acceso.

## Mensaje obligatorio
"Este es un registro ciudadano independiente. Reportar daños o necesidades no garantiza una inspección ni la entrega de ayuda. Si existe peligro inmediato, contacte a las autoridades de emergencia."

## Estado
Especificación funcional. No implica que el formulario, el backend o el panel estén implementados.
